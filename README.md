# 水下考古潜水记录

## 连续潜次放行台（`release.html`）

规则、记录、页面拆分为三个业务文件，直接打开 `release.html` 即可使用：

- `rules.js` — 规则层（纯函数）：相邻潜次间隔不足一小时不得开始后一潜；可下水余量按前一潜“深度 × 时长”负荷折减三成（`max(0, 480 - 0.3 × 深度 × 时长)`）；前一潜未登记出水时刻，后一潜只留**待复核**，不进入时间线。
- `records.js` — 记录层：潜次/标记登记、修订留档、幂等提交、localStorage 持久化、JSON 导出。
- `page.js` — 页面层：放行队列、潜次时间线、关联标记清单与表单交互。

行为约定：

- 修订任一潜次后，后续放行结论与关联标记状态按新值整条重算；旧版本留档，不进入导出。
- 重复或并发提交按提交内容命中幂等键，沿用首次结果；提交期间按钮锁定。
- 每次加载都按当前版本重算，放行队列刷新后一致。

## 沉船平面图标记（`index.html`）

点击平面图添加标记，支持筛选、编辑、删除、时间线和导出 JSON。
